# NeuralNet

## Neural Networks examples in Java using DeepLearning4j Core and ND4J Native Platform 

## This is a Eclipse Maven project featuring the following examples:
- **XOR gate** realizzato con una rete multilayer
- **Parity bit** , calcolo del bit di parità su un byte
- **Sommatore a 4 bit (ToDo)** , somma due nibbles senza riporto
- **Shift register DX a 4 bit (ToDo)** , shifta un nibble di una posizione a destra (divisione per 2)
