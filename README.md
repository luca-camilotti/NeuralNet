# NeuralNet

## Neural Networks examples in Java using DeepLearning4j Core and ND4J Native Platform 

## This is a Eclipse Maven project featuring the following examples:
- **XOR gate** implemented with a multilayer network
- **Parity bit**, calculation of the parity bit on a byte
- **4-bit adder (ToDo)**, adds two nibbles without carry
- **4-bit right shift register (ToDo)**, shifts a nibble one position to the right (division by 2)
